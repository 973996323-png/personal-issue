在终端里安装（推荐程序员使用）

只需要下面这一行命令，复制粘贴到终端（Terminal）里，回车即可：

$ npm install -g @anthropic-ai/claude-code
  1. 装好后，在终端里输入 claude 并回车
  2. 根据提示登录你的账号
  3. 之后直接用中文对话，它就会开始帮你干活
💡 前提：电脑上已装有 Node.js。没有的话，先去 nodejs.org 下载安装一个。

和微信、Chrome 一样，装一个应用程序，点图标就能用。支持 Mac 和 Windows。

  1. 访问官方下载页：claude.com/product/claude-code

如果你已经在用 VS Code 或 JetBrains 系列（如 IDEA、PyCharm），可以直接装插件，边写代码边让它帮忙。

  2. 搜索 Claude Code
  3. 点击「安装 Install」，然后按提示登录即可
