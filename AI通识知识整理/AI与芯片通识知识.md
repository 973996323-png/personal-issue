## 一、机器人逆解（Inverse Kinematics）

### 1.1 问题定义

- **正解（FK）**：已知各关节角度 → 计算末端执行器的空间位姿。简单几何计算，解唯一。
- **逆解（IK）**：已知目标位姿 → 反推各关节角度。是"目标位姿 → 关节角度"的翻译官。

### 1.2 难点

| 难点 | 说明 |
|---|---|
| 解不唯一 | 同一目标位置，机械臂可以"肘上"或"肘下"到达 |
| 可能无解 | 目标超出工作空间 |
| 无解析解 | 复杂构型推不出公式，只能数值迭代 |
| 奇异性 | 某些姿态下机械臂"卡住"，失去自由度 |

### 1.3 两大方法

**方法 1：解析法（封闭解）**——以平面 2 连杆臂为例，用余弦定理一步出结果：

```
cos(θ2) = (x² + y² − L1² − L2²) / (2·L1·L2)
θ1 = atan2(y, x) − atan2(L2·sinθ2, L1 + L2·cosθ2)
```

- 优点：快、精确、能给出全部解
- 缺点：只对特定构型可行

**方法 2：数值法（雅可比迭代 / 阻尼最小二乘 DLS）**

1. 猜一组关节角 θ
2. 用正解算当前末端位置，得误差 e = 目标 − 当前
3. 用雅可比矩阵算修正量：Δθ = Jᵀ(JJᵀ + λ²I)⁻¹ · e
4. 更新 θ，重复至误差足够小

- 优点：通用，适用于任意机械臂
- 缺点：迭代慢、依赖初值、可能陷入局部最优

工程实践：6 自由度机械臂常用解析法（Pieper 准则）或库（TRAC-IK、IKPy、MoveIt）。

## 二、VLA：视觉-语言-动作模型

### 2.1 核心思想

传统机器人是"分层管线"，VLA 是"端到端"：

```
传统：感知 → 规划 → 运动规划 → 逆解 → 关节控制
VLA： 相机图像 + 语言指令 → 大模型 → 直接输出动作
```

**关键：VLA 不显式计算物体坐标**，映射关系（像素→动作）全部从示教数据中学习，隐含在权重里。

### 2.2 数据从哪来：遥操作示教

人戴 VR 手柄或用主从臂操作机器人完成任务，系统同步记录每一帧：

- 相机图像（多视角）
- 语言指令（"把苹果放进篮子"）
- 关节角度（编码器直接读出，无需人工标注）
- 末端位姿（正解算出）
- 动作标签 = 人下一步的操作量

公开数据集：Open X-Embodiment（百万级轨迹）。

### 2.3 动作怎么表示

| 表示 | 内容 | 与逆解的关系 |
|---|---|---|
| 末端位姿空间 | [Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper] | **仍需逆解**转关节角 |
| 关节空间 | [Δθ1...Δθ6, gripper] | 跳过逆解，但绑死特定机器人 |

数值生成两条路线：

- **离散 token**（RT-2、OpenVLA）：动作维度切成 256 区间，像生成文字一样生成，交叉熵训练
- **连续生成**（π0、Diffusion Policy）：diffusion / flow matching 从噪声去噪成平滑轨迹

技巧：**action chunking**（ACT）——一次输出未来 20~50 步动作，执行一段再重新观察，更平滑抗抖动。

### 2.4 架构与训练

```
相机图像 → 视觉编码器(ViT) ──┐
语言指令 → tokenizer ────────┼→ LLM 骨干 → 动作头 → 动作
关节状态(可选) ─────────────┘   (token头 / diffusion头)
```

- 视觉编码器和 LLM 骨干**复用现成多模态大模型**（语义泛化能力的来源）
- 训练 = **行为克隆**（监督学习）：`loss = 匹配(预测动作, 人的动作)`
- 推理 = **闭环控制**：执行几步 → 重新观察画面 → 纠偏

### 2.5 优势与局限

- ✅ 泛化强、一个模型多任务
- ❌ 极吃示教数据、推理慢（几十~上百 ms）、精度有限

代表工作：RT-2、OpenVLA（开源）、π0/π0.5、RDT 等。

### 2.6 VLA 与逆解的分工

| | 逆解 IK | VLA |
|---|---|---|
| 问题 | 位姿 → 关节角 | 图像+语言 → 动作 |
| 函数 | 已知（几何公式） | 写不出来，从数据学 |
| 角色 | 底层执行环节 | 上层决策环节 |

**VLA 决定"末端往哪动"，IK 负责"关节怎么转"。** 两者配合，不是替代。

## 三、AI 基本概念

### 3.1 包含关系

```
AI（人工智能）
 └─ 机器学习（从数据中学规律，不写死规则）
     └─ 深度学习（用深层神经网络做机器学习）
         └─ 大模型（参数量巨大的神经网络，如 LLM）
```

**澄清：不是所有 AI 都用神经网络。** 历史上还有：

- 专家系统（人工写规则库，80 年代主流）
- 搜索算法（深蓝下棋）
- 传统机器学习（决策树、SVM、贝叶斯——表格数据上至今好用）

只是 2012 年后深度学习在图像/语音/语言上碾压其他方法，"AI"几乎成了深度学习的代名词。

## 四、神经网络的本质与学习原理

### 4.1 一个神经元

```
输出 = f(w1·x1 + w2·x2 + w3·x3 + b)
```

- **w（权重）**：每个输入的重要程度 = 要学习的参数
- **f（激活函数）**：非线性开关，让网络能表达复杂边界

数学上有"万能逼近定理"：足够多的神经元分层堆叠，可逼近任意复杂函数。

### 4.2 学习 = 调权重

```
1. 随机初始化权重（输出瞎猜）
2. 喂样本 → 计算损失（错得多离谱）
3. 反向传播：算每个权重对错误的"贡献"
4. 梯度下降：每个权重往减错方向调一小步
5. 重复几百万次
```

**核心洞察：学习 = 用海量数据自动调节数百万个旋钮（权重），让输入→输出的映射逼近目标。**

网络会自动分层提取特征（低层认边缘 → 中层认器官 → 高层认整体），无人教它这个层级，是自己"长出来"的。

## 五、大语言模型如何工作

### 5.1 四步流程

**第 1 步：文字 → 数字**

```
"今天天气怎么样" → 分词 → token ID → Embedding（高维向量）
```

Embedding 的精妙：**意思相近的词，向量也相近**（"国王−男人+女人≈女王"）。

**第 2 步：Transformer（自注意力）**

处理每个词时，模型"回头看"句子中所有词，计算相关度。例：处理"它"时强烈关注"手机"而非"苹果"。一词多义、长距离指代全靠它。注意力层堆几十上百层。

**第 3 步：唯一的工作——预测下一个 token**

```
输入"中国的首都是" → 计算词表概率 → "北京":92% → 接上 → 再预测 → ...
```

**回答就是逐字"接龙"接出来的**，每个字背后是完整的一次前向传播。

**第 4 步：训练两阶段**

- **预训练**：读遍互联网（万亿 token），遮住下一个词让模型猜。**要猜得准，被迫学会语言背后的知识**——知识是接龙能力的副产品，被压缩进权重。
- **后训练**：指令微调（SFT，学会"该回答而非续写"）+ 人类反馈强化学习（RLHF，偏向有用/无害/诚实）。

### 5.2 常见疑问

- 模型"理解"我吗？——哲学问题。工程上它学到了一个函数，输入你的话输出统计上最合理的回应。
- 为什么会幻觉？——目标是"接得像"不是"说得对"，没有内置事实核查。

## 六、大模型发展的六堵墙

1. **数据墙**：公开高质量文本（几百万亿 token）快被用完；合成数据防"近亲繁殖"。出路：私有数据、多模态、具身数据。
2. **算力/能源墙**：训练一次上亿美元，几万~几十万张 GPU；数据中心从百 MW 冲向 GW 级（≈中型城市用电）。
3. **Scaling 收益递减**：参数翻 10 倍，智能提升越来越小。转向**推理时扩展**（test-time compute，如 o 系列/R1 的"多想一会"）。
4. **架构天花板**：幻觉、上下文有限（注意力 O(n²)）、无真正记忆、缺世界模型、自回归生成慢。
5. **硬件物理极限**：制程逼近原子尺度（量子隧穿），摩尔定律失效；**内存墙**——算力增长远快于显存带宽，瓶颈常在"搬数据"。
6. **评估与对齐**：benchmark 被刷爆；能力越强对齐越难。

突围方向：推理时思考、Agent、合成数据、新架构、具身数据。

## 七、芯片原理：从 0 和 1 到完成任务

### 7.1 分层总览

```
第 0 层：0 和 1 = 高/低两种电压（可靠性选择，非数学必须）
第 1 层：晶体管 = 电控开关（现代 CPU 有几百亿个）
第 2 层：逻辑门 = 开关组成的判断电路（NOT/AND/OR）
第 3 层：加法器 = 逻辑门拼出算术（异或=和，与=进位）
第 4 层：存储 = 触发器环路让电路有"记性"
第 5 层：指令 = 程序也是存在内存里的 0/1 序列
第 6 层：模块 = CPU/GPU/NPU/内存/SSD/控制器……
```

### 7.2 晶体管（MOSFET）

栅极加电压 → 沟道导通；撤电压 → 断开。无机械部件，每秒开关几十亿次，尺寸几十纳米。"3nm 制程"形容晶体管多小——越小越省电、越快、越密集。

### 7.3 加法器：数学变成电路

二进制加法：`0+0=0, 0+1=1, 1+1=10（进位）`。"和"位=异或，"进位"位=与。64 个全加器串联 → 一次时钟周期完成 64 位加法。ALU（算术逻辑单元）干这个。**芯片不是"理解"数学，是人把数学翻译成了电路通断规律。**

### 7.4 存储金字塔

| 层级 | 材料 | 速度 | 容量 | 类比 |
|---|---|---|---|---|
| 寄存器 | 触发器 | ~0.3ns | 几百字节 | 手里的笔 |
| L1/L2/L3 缓存 | SRAM | ~1-10ns | KB~几十MB | 桌上草稿纸 |
| 内存 RAM | DRAM | ~100ns | 16GB | 书架 |
| SSD | NAND 闪存 | ~100μs | TB 级 | 仓库 |

### 7.5 指令与冯·诺依曼架构

程序和数据都是内存里的 0/1。CPU 循环：取指 → 译码 → 执行 → 写回，由时钟驱动（3.5GHz = 每秒 35 亿次节拍）。指令集分 x86（Intel/AMD）与 ARM（苹果 M 系列/手机）。

### 7.6 笔记本模块

| 模块 | 负责 | 特点 |
|---|---|---|
| CPU | 通用计算 | 4~24 个强核心，什么都能算 |
| GPU | 并行计算 | 上万小核心，图形渲染 + AI |
| NPU | 本地 AI | 专为神经网络优化，省电 |
| 内存 RAM | 临时工作台 | 断电即清空 |
| SSD | 永久存储 | 文件、模型权重 |
| 控制器/总线 | 数据搬运"交警" | PCIe |
| 电源管理 / 时钟 | 供电 / 统一节拍 | 晶振 |

## 八、神经网络 = 矩阵乘法：CPU/GPU/NPU 的分工

### 8.1 加权求和就是矩阵乘法

一个神经元 = 向量点积；一层神经元 = 矩阵 × 向量；一批样本 = 矩阵 × 矩阵。前向传播 = 矩阵乘法与激活函数交替：

```
输出 = f(W₃ · f(W₂ · f(W₁·x + b₁) + b₂) + b₃)
```

特点：**海量、独立、整齐的乘加运算**。

### 8.2 CPU vs GPU

| | CPU | GPU |
|---|---|---|
| 设计哲学 | 为**延迟**优化 | 为**吞吐量**优化 |
| 晶体管花在 | 控制逻辑、大缓存 | 几乎全是计算单元 |
| 核心 | 8~24 个强核心 | 16384 个小核心 |
| 算力 | ~1-2 TFLOPS | ~82 TFLOPS（FP32） |
| 带宽 | ~80 GB/s | ~1000 GB/s |

- 分支多、有依赖的串行任务（OS、浏览器逻辑）→ CPU
- 海量独立乘加（矩阵乘）→ GPU
- "CPU 为什么不多做一点"：晶体管预算就那么多，加一万个核心就得砍分支预测——它就变成了 GPU。Amdahl 定律：串行部分决定加速上限。
- 大模型推理瓶颈常在**搬数据**（每生成一字要读全部权重），GPU 高带宽就是为此时准备的。

### 8.3 显卡为什么贵

你买的是**整块子系统**而非裸芯片：GPU 芯片本体（608 mm²、760 亿晶体管，良率超线性下降）+ 24GB GDDR6X 显存 + 十几相供电 + 三风扇散热 + 多层 PCB。数据中心 H100/B200 一张 3~4 万美元，HBM 显存是成本大头。

### 8.4 NPU 的优化手段

核心事实：**搬运数据的能耗比计算本身高几十~几百倍** → 一切设计围绕"让数据少动"。

1. **脉动阵列**：MAC 单元排成网格，权重驻留不动，数据流过即完成乘加
2. **低精度**：神经网络对精度宽容，INT8/INT4 乘法器面积功耗只有 FP32 的几十分之一（量化技术）
3. **砍掉控制赘肉**：无乱序执行/分支预测，面积全换 MAC

指标 TOPS（每秒万亿次运算）：苹果 M4 NPU 38 TOPS，Copilot+ PC 门槛 40 TOPS。GPU 的 Tensor Core 本质也是内嵌脉动阵列——GPU 与 NPU 界限在模糊。

## 九、存储介质：断电后数据去哪了

### 9.1 SSD（NAND 闪存）：把电子关进笼子

浮栅被绝缘层完整包裹，电子出不来 → 断电不丢。两个软肋：

1. **写入磨损**：高压轰击绝缘层，擦写寿命 TLC 约 1000~3000 次，QLC 几百次（家用够用十几年）
2. **电荷泄漏**：电子缓慢逃逸，温度越高漏越快。JEDEC 标准：消费级 SSD 寿命末期断电存放至少保 1 年（30°C）

### 9.2 HDD（机械硬盘）：磁畴方向

磁化方向上=1 下=0，不靠电维持。数据保持远好于 SSD（理论几十年），但电机/轴承/润滑脂会老化——**数据可能还在，盘却转不起来了**。

### 9.3 "50 年之问"

| 介质 | 50 年后断电存放 |
|---|---|
| SSD | 数据几乎肯定全丢（电子漏光） |
| HDD | 磁记录可能大部分在，但机械大概率失效 |
| 普通光盘 | 染料老化，大概率读不出 |
| M-DISC 归档光盘 | 宣称百年级 |
| 磁带 LTO | 标称 30 年，企业冷备主流 |

**核心结论：数据不是靠"活得久的介质"保存，而是靠"不断复制"保存。** 实践 3-2-1 备份：3 份副本、2 种介质、1 份异地（如云端），每隔几年迁移到新介质。

## 十、大模型如何生成回答：完整流程

1. **知识不在原文里，在权重里**：训练把万亿文本的规律与事实压缩进几千亿权重（不存原文 → 会记错、会幻觉）。回答 = 压缩知识被问题激活后**重组生成**，故能回答没人问过的问题（泛化而非检索）。
2. **输入**：整个对话历史一起分词 → token ID → 向量。
3. **前向传播**：权重从 HBM 显存搬出，每层做矩阵乘法，注意力关联上下文。
4. **逐字生成**：输出词表概率分布 → 选一个 token → 接上 → 再算。每个字 = 几千亿次矩阵乘法。
5. **结构从哪来**：好解释方式本身是可学模式（先破误解再讲原理、给类比）；RLHF 强化清晰友好；已生成文字成为后续上下文，"边想边说"。
6. **诚实局限**：模型无法真正检查自己权重，"我是怎么想的"部分是生成的自我叙述——可解释性是未解难题。
7. **何时联网搜索**：概念性知识直接用权重；时效性问题（新闻/股价）必须搜；拿不准的事实该搜，否则易幻觉。

## 十一、大模型的存储占用

### 11.1 计算公式

```
存储占用 = 参数数量 × 每参数字节数
```

| 模型 | 参数量 | FP16 (2B) | INT8 (1B) | INT4 (0.5B) |
|---|---|---|---|---|
| GPT-3 | 175B | 350 GB | 175 GB | ~88 GB |
| LLaMA 3.1 | 405B | 810 GB | 405 GB | ~200 GB |
| DeepSeek V3 | 671B (MoE) | 1.3 TB | 671 GB | ~335 GB |

训练时还需梯度+优化器状态，总需求达推理的 4~8 倍。

### 11.2 模型 = 互联网的压缩包

训练数据 ~60TB → 权重 350GB，压缩率约 **170:1**（有损，存规律不存原文）。

### 11.3 知识涨，存储不一定涨

1. **量化**：INT4 存储缩到 1/4，性能损失 <1%
2. **蒸馏**：大模型教小模型，7B 追平当年 175B
3. **MoE**：总参数可涨，单次激活不涨（DeepSeek V3 总 671B 只激活 37B）
4. **RAG**：不把知识背进权重，需要时现查

**趋势**：2020-2023 军备竞赛体积暴涨；2023 后两头分化（旗舰靠 MoE/量化控制开销，实用模型疯狂瘦身）。看模型发布别只看参数量，看"**激活参数 × 精度位数**"。
