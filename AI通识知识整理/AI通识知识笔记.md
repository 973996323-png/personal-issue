## 一、机器人逆解（IK）

### 1.1 正解与逆解

- **正解（Forward Kinematics）**：已知各关节角度 → 计算末端（夹爪）在空间中的位置和姿态。简单几何计算，答案唯一。
- **逆解（Inverse Kinematics）**：已知目标位置/姿态 → 反求各关节角度。

### 1.2 为什么难

1. **解不唯一**：同一目标位置，"肘部朝上"和"肘部朝下"都能够到。
2. **可能无解**：目标超出工作空间。
3. **可能没有解析解**：很多构型推不出公式，只能数值迭代。
4. **奇异性**：某些姿态下机械臂失去自由度。

### 1.3 两类解法（以平面 2 连杆臂为例）

正解公式：

```
x = L1·cos(θ1) + L2·cos(θ1 + θ2)
y = L1·sin(θ1) + L2·sin(θ1 + θ2)
```

**解析法**（余弦定理，一步出封闭解）：

```
cos(θ2) = (x² + y² − L1² − L2²) / (2·L1·L2)
θ1 = atan2(y, x) − atan2(L2·sinθ2, L1 + L2·cosθ2)
```

- `|cos(θ2)| > 1` → 目标不可达，无解
- `sin(θ2)` 取正/负 → 对应肘部下/上两个解

**数值法**（雅可比阻尼最小二乘 DLS，迭代逼近）：

```
循环：
  1. 用正解算当前位置，得误差 e = 目标 − 当前
  2. 误差足够小 → 收敛退出
  3. 计算雅可比矩阵 J（末端位置对关节角的偏导数）
  4. Δθ = Jᵀ(JJᵀ + λ²I)⁻¹ · e
  5. θ ← θ + Δθ
```

- 解析法：快、精确、能给出全部解，但只对特定构型可行
- 数值法：通用，但依赖初值、可能陷入局部、需要迭代

## 二、VLA：视觉-语言-动作模型

### 2.1 核心思想

传统机器人管线：

```
❌ 识别物体 → 算坐标 → 规划轨迹 → 逆解 → 执行   （分层、各环节手写规则）
```

VLA（端到端）：

```
✅ 图像 + 语言指令 → 神经网络 → 直接输出动作
```

中间**没有显式的"物体坐标"环节**——坐标、抓取姿态等知识隐含在网络权重里。

### 2.2 训练数据：遥操作示教

人戴着 VR 手柄 / 主从臂操作机器人做任务，系统同步记录每一帧（如 30Hz）：

- 相机图像（多视角）
- 语言指令（如"把苹果放进篮子"）
- 关节角度（编码器直接读出，**无需人工标注**）
- 末端位姿（正解一算即得）
- 动作标签 = 人下一步让机器人怎么动

公开数据集：**Open X-Embodiment**（百万级轨迹、几十种机器人）。

### 2.3 动作表示

**动作空间**两种选择：

| 空间 | 形式 | 特点 |
|---|---|---|
| 末端位姿 | [Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper] | 常见，**需要逆解接棒**转成关节角 |
| 关节空间 | [Δθ1...Δθ6, gripper] | 跳过逆解，但模型绑死单台机器人 |

**数值→模型输出**两条路线：

| 路线 | 代表 | 做法 |
|---|---|---|
| 离散化 token | RT-2、OpenVLA | 每维切 256 个区间，动作变成"词"，像生成文字一样生成，交叉熵损失 |
| 连续生成 | π0、Diffusion Policy | diffusion / flow matching，从噪声去噪成连续动作轨迹，平滑精细 |

**Action chunking**（ACT 提出）：一次输出未来 20~50 步动作序列，执行一段后重新观察——更平滑、抗抖动。

### 2.4 模型架构

```
相机图像 ──→ 视觉编码器(ViT) ──→ 图像 token ─┐
                                              ├─→ LLM 骨干 ──→ 动作头 ──→ 动作
语言指令 ──→ tokenizer ──────────────────────┘    (离散token头 / diffusion头)
关节状态(可选) ──────────────────────────────┘
```

- 视觉编码器 + LLM 骨干**不从头训练**，直接拿现成多模态大模型 → 语义泛化能力的来源
- 机器人数据只微调出"输出动作"的能力

### 2.5 训练与推理

**训练 = 行为克隆（监督学习）**：

```python
for image, instruction, state, human_action in dataset:
    pred = VLA(image, instruction, state)
    loss = 匹配损失(pred, human_action)   # 交叉熵 或 扩散损失
    loss.backward()
```

**推理 = 闭环控制**：

```python
while 任务未完成:
    image = 相机.read()
    action_chunk = VLA(image, 指令, 当前关节角)
    for action in action_chunk[:K]:
        关节角 = 逆解(action)   # 若动作在末端位姿空间
        电机执行(关节角)
    # 重新观察，抓偏了下一步能纠正
```

### 2.6 代表工作

- **RT-2**（Google DeepMind, 2023）：动作离散成 token
- **OpenVLA**（2024，开源）：7B 参数，基于开源多模态模型微调
- **π0 / π0.5**（Physical Intelligence）：flow matching，叠衣服等灵巧任务
- 国内：RDT、智元、银河通用等

### 2.7 IK 与 VLA 的分工

| | 逆解 IK | VLA |
|---|---|---|
| 问题 | 位姿 → 关节角 | 图像+语言 → 动作 |
| 函数 | 已知（几何公式） | 写不出来，从数据中学 |
| 角色 | 底层执行 | 上层决策 |

**VLA 决定"末端该往哪动"，IK 负责"关节怎么转才能实现"——配合，不是替代。**

```
┌─ AI（人工智能）：让机器表现出智能，方法有很多种
│  ┌─ 机器学习：不写死规则，从数据中学规律
```

2012 年后神经网络在图像/语音/语言上碾压其他方法，"AI"才几乎成了"深度学习"的代名词。

## 四、神经网络的基本原理

### 4.1 一个神经元 = 加权求和 + 非线性开关

```
输出 = f(w1·x1 + w2·x2 + w3·x3 + b)
```

- `w`（权重）：要学习的参数
- `f`（激活函数）：引入非线性，让网络能表达复杂边界

单个神经元只能线性分类；**几百万个分层堆叠**可逼近任意复杂函数（万能逼近定理）。

### 4.2 学习 = 调权重

以识别猫图为例：

```
1. 随机初始化权重（输出是瞎猜）
2. 喂猫图 → 输出"狗"（错了）
3. 计算损失 loss：错得多离谱
4. 反向传播：每个权重对错误"贡献"多少
5. 梯度下降：每个权重往减少错误方向调一小步
6. 重复几百万次 → 权重调好
```

**核心洞察：学习 = 用海量数据自动调节几百万个旋钮。** 没人写"猫有尖耳朵"这种规则——网络自己学会分层提取特征：低层认边缘，中层认眼睛，高层认"猫脸"。

## 五、大语言模型如何"你问它答"

### 四步流程

**1. 文字 → 数字**
- 分词（tokenizer）→ token ID → Embedding 向量
- 训练后意思相近的词向量相近："国王 − 男人 + 女人 ≈ 女王"

**2. Transformer + 自注意力（Self-Attention）**
- 处理每个词时"回头看"所有其他词，计算相关度
- 解决一词多义、长距离指代（"它"指代"手机"而非"苹果"）

**3. 本质工作：预测下一个 token**

> 大语言模型做的唯一一件事：给定前面的文字，预测下一个 token 最可能是什么。

回答就是逐字"接龙"接出来的，每个字背后是一次完整的前向计算。

**4. 训练两阶段**

- **预训练**：读几万亿 token 文本，玩"遮字预测"。要接对"巴黎是法国的首都"，模型被迫学会世界知识——知识是"接龙能力"的副产品
- **后训练**：指令微调（SFT，学会"该回答而非续写"）+ RLHF（人类偏好打分，偏向有用/无害/诚实）

### 常见疑问

| 疑问 | 回答 |
|---|---|
| 模型"理解"我吗？ | 哲学问题。工程上：学到了输入→最合理回应的映射 |
| 为什么会幻觉？ | 目标是"接得像"不是"说得对"，无内置事实核查 |

## 六、大模型发展的六堵墙

1. **数据墙**：人类公开高质量文本（几百万亿 token 量级）快用完了；合成数据有"近亲繁殖"风险。出路：私有数据、多模态、具身数据
2. **算力与能源墙**：单次训练上亿美元、几万~几十万张 GPU；数据中心从 MW 冲向 GW 级用电（≈一座中型城市）
3. **Scaling Law 边际收益递减**：参数翻 10 倍，智能提升越来越小。出路：**推理时扩展**（test-time compute，o 系列/R1 推理模型，"多想一会"）
4. **架构天花板**：幻觉、上下文 O(n²)、无真正记忆、缺世界模型、自回归生成慢
5. **硬件物理极限**：3nm/2nm 逼近原子尺度、量子隧穿、摩尔定律失效；**内存墙**——搬数据比算更慢
6. **评估与对齐**：benchmark 被刷爆；能力增长快于安全投入

**突围方向**：推理时思考、Agent、合成数据、新架构（Mamba 等）、具身智能。

## 七、芯片：从 0 和 1 到完成一切

### 7.1 自下而上的层次

**第 0 层：0 和 1 = 两种电压**
- 高电压 ≈ 1，低电压 ≈ 0
- 选二进制是**可靠性**的工程选择：区分两种状态抗噪声

**第 1 层：晶体管（MOSFET）= 电控开关**
- 栅极加电压 → 沟道导通；撤掉 → 断开
- 无机械部件，每秒开关几十亿次，尺寸几十纳米
- 一颗现代 CPU 有**几百亿个**

**第 2 层：逻辑门**
- 非门 NOT、与门 AND、或门 OR
- 与门 = 两个晶体管串联（都导通电流才通）

**第 3 层：加法器**——逻辑门拼出算术
- 半加器：和 = A⊕B（异或），进位 = A·B（与）
- 64 个全加器串联 = CPU 一个时钟周期完成 64 位加法
- **芯片不是"理解"数学，是有人把数学翻译成了电路通断规律**

**第 4 层：存储金字塔**

| 层级 | 材料 | 速度 | 容量 | 类比 |
|---|---|---|---|---|
| 寄存器 | 触发器 | ~0.3ns | 几百字节 | 手里的笔 |
| L1/L2/L3 缓存 | SRAM | ~1-10ns | KB~MB | 桌上草稿纸 |
| 内存 RAM | DRAM | ~100ns | 16GB | 书房书架 |
| SSD | NAND 闪存 | ~100μs | 512GB+ | 仓库 |

**第 5 层：指令**
- 程序和数据都是内存里的 0/1（冯·诺依曼架构）
- x86（Intel/AMD）vs ARM（苹果 M 系列/手机）
- CPU 循环：取指 → 译码 → 执行 → 写回，每秒几十亿次（GHz）
- 现代技巧：流水线、乱序执行、分支预测

### 7.2 笔记本里的模块

| 模块 | 负责 |
|---|---|
| CPU | 通用计算：操作系统、浏览器，几个强大核心 |
| GPU | 并行计算：图形渲染、AI，上千个小核心 |
| NPU | 本地 AI：矩阵乘加专用电路 |
| 内存 RAM | 运行时工作台，断电即清 |
| SSD | 永久存储 |
| 内存/IO 控制器 | 数据搬运交警（PCIe） |
| Wi-Fi/蓝牙、电源管理、时钟（晶振） | 各专用功能 |

苹果 M 系列 = SoC，把以上集成进一颗芯片。

## 八、加权求和 = 矩阵乘法

一层 3 神经元、2 输入：

```
y1 = w11·x1 + w12·x2 + b1
y2 = w21·x1 + w22·x2 + b2        ⟺   y = W·x + b
y3 = w31·x1 + w32·x2 + b3
```

矩阵乘法的定义"行×列对应相乘再求和"**就是加权求和**：

- 1 个神经元 = 向量点积
- 1 层 = 矩阵 × 向量
- 一批样本 = 矩阵 × 矩阵

整个前向传播：`输出 = f(W₃·f(W₂·f(W₁·x+b₁)+b₂)+b₃)`——全是矩阵乘法夹激活函数。训练反向传播同样。千亿参数模型一次前向 = **几千亿次乘加，海量、独立、整齐**。

## 九、CPU vs GPU vs NPU

### 9.1 CPU 为什么"不多做一点"

同一份晶体管预算的两种花法：

- **CPU 为延迟优化**：大部分晶体管花在控制逻辑（乱序、分支预测）和大缓存上，真正算数的 ALU 只占小面积
- **GPU 为吞吐优化**：砍掉控制逻辑，面积全换计算单元

| | 高端 CPU | RTX 4090 |
|---|---|---|
| 核心 | 8~24 个强核 | 16384 个小核 |
| 算力 | ~1-2 TFLOPS | ~82 TFLOPS（FP32） |
| 带宽 | ~80 GB/s | ~1000 GB/s |

任务分工：分支多、有依赖的串行任务 → CPU；海量独立乘加 → GPU。给 CPU 加一万个核心它就变成了 GPU——**这是权衡，不是强弱**。

大模型推理瓶颈常在**搬数据**而非算（每生成一字要把全部权重从显存读一遍），所以带宽是命根子。

### 9.2 显卡为什么贵

显卡 = 一整块子系统，不是一颗裸芯片：

- GPU 芯片：608 mm²、760 亿晶体管（CPU 通常 100~200 mm²）。硅片按面积卖钱，大芯片良率超线性下降
- 显存：24GB GDDR6X 高带宽颗粒
- 供电（十几相）、散热（三风扇均热板）、十几层 PCB
- 市场：游戏 + 挖矿 + AI 抢卡
- 商用：H100/B200 一张 3~4 万美元，成本大头是 HBM 堆叠显存

### 9.3 NPU 的优化之道

出发点：**搬数据的能耗比计算本身高几十~几百倍** → 让数据少动。

1. **脉动阵列**：乘加单元（MAC）排成网格，权重驻留不动，数据流过即完成乘法，结果向下累加
2. **低精度**：神经网络对精度宽容，INT8/INT4 几乎无损；8 位乘法器面积/功耗只有 32 位浮点的几十分之一（量化）
3. **砍掉控制赘肉**：无乱序、无分支预测，面积全换 MAC

指标 **TOPS**：苹果 M4 NPU 38 TOPS，仅几瓦功耗；Copilot+ PC 门槛 ≥40 TOPS。GPU 的 Tensor Core 本质也是内嵌脉动阵列——GPU 与 NPU 界限在模糊。

## 十、存储：断电后数据去哪了

### 10.1 SSD（NAND 闪存）：把电子关进笼子

- 浮栅被绝缘层完整包裹，电子关在里面 = 0/1，断电不丢
- **软肋 1 磨损**：擦写靠高压轰击绝缘层，TLC 约 1000~3000 次 P/E（家用写寿命十几年，不用焦虑）
- **软肋 2 漏电**：电子缓慢逃逸，温度越高越快。JEDEC 标准：消费级 SSD 寿命末期 30°C 断电**只保证 1 年**

### 10.2 HDD（机械硬盘）：磁畴方向

- 磁化方向 = 0/1，不靠电维持，理论可保持几十年
- 但电机/轴承/润滑脂会老化——数据还在，盘可能转不起来

### 10.3 "50 年之问"答案

| 介质 | 断电 50 年 |
|---|---|
| SSD | **几乎肯定全丢** |
| HDD | 磁记录可能还在，但机械多半失效，需开盘抢救 |
| 普通光盘 | 染料老化，大概率读不出 |
| M-DISC 归档光盘 | 宣称百年级 |
| LTO 磁带 | 标称 30 年 |

> **数据不靠"活得久的介质"保存，而靠"不断复制"保存。**
> 3-2-1 备份：3 份副本、2 种介质、1 份异地。数字保存 = 定期迁移到新介质，如同古籍靠一代代抄写流传。

## 十一、大模型自己是怎么生成回答的

1. **不是提前喂过答案**：没人预想过你的具体问题；也不是"问答对照表"检索
2. **知识压缩在权重里**：训练时读几万亿字，知识不是原文存储，而是分布式压缩在海量权重中（像"盐味"不存在于单个 NaCl 分子）
3. **回答 = 泛化重组**：学到的语言/知识内在结构被你的问题激活、重组，生成从未存在过的新文字——所以能回答没人问过的问题
4. **流程**：整个对话历史 → 分词 → Transformer 前向传播（GPU 矩阵乘法）→ 逐 token 采样输出，每字都是几千亿次计算
5. **"思考"与结构**：好解释方式本身也是可学习的模式；RLHF 强化了"对初学者友好、结构清晰"的倾向；前面生成的文字成为后续的上下文，边写边组织
6. **诚实的局限**：模型无法检查自己的权重，"自述思考过程"部分是架构事实、部分是生成的自我叙述；可解释性仍是难题
7. **何时联网搜索**：概念知识直接用权重；时效性问题必须搜索（训练数据有截止日期）；拿不准的事实应搜索验证，否则可能幻觉

## 十二、大模型的存储占用

### 12.1 算法

```
存储 = 参数量 × 每参数字节数
FP16 = 2 字节/参数；INT8 = 1；INT4 = 0.5
```

| 模型 | 参数 | FP16 | INT4 |
|---|---|---|---|
| GPT-3 | 175B | 350 GB | ~88 GB |
| LLaMA 3.1 405B | 405B | 810 GB | ~200 GB |
| DeepSeek V3 (MoE) | 671B | 1.3 TB | ~335 GB |

GPT-3 权重 ≈ 两个大型游戏安装包。训练还要加梯度 + 优化器状态（Adam 每参数 2 个历史量），达推理的 4~8 倍。

### 12.2 模型是互联网的压缩包

```
15 万亿 token ≈ 60 TB 文本 → 350 GB 权重 ≈ 170:1 有损压缩
```

不存原文（所以会记错具体数字、会幻觉），只存规律。

### 12.3 知识涨 ≠ 存储无限膨胀：四条省存储的路

1. **量化**：INT4 缩到 1/4，性能损失 <1%
2. **蒸馏**：大模型教小模型。现在 7B 可追平当年 175B 的 GPT-3
3. **MoE**：DeepSeek V3 总 671B 但每次只激活 37B——知识分房间存放，单次成本不涨
4. **RAG**：不把维基百科背进权重，会查就行——模型小、知识无限

**趋势**：2020-2023 军备竞赛暴涨；之后两头分化——旗舰靠 MoE/量化控制开销，实用模型疯狂瘦身。看新模型别只看参数量，看**激活参数 × 精度位数**。
