## 一、机器人逆解（IK）

### 1.1 正解与逆解

- **正解（Forward Kinematics）**：已知每个关节角度 → 算出末端（夹爪）在空间的位置和姿态。简单几何计算，答案唯一。
- **逆解（Inverse Kinematics）**：已知目标位置/姿态 → 反求每个关节应转多少度。

### 1.2 逆解难在哪

1. **解不唯一**：同一目标位置，"肘上"和"肘下"都能够到。
2. **可能无解**：目标超出工作空间。
3. **可能没有解析解**：很多构型推不出公式，只能数值迭代。
4. **奇异性**：某些姿态下机械臂失去运动自由度。

### 1.3 两类求解方法

| 方法 | 思路 | 特点 |
|---|---|---|
| 解析法（封闭解） | 余弦定理等推导公式 | 快、精确，只对特定构型可行 |
| 数值法 | 雅可比迭代、阻尼最小二乘（DLS）逼近 | 通用，但依赖初值、可能陷入奇异点 |
| 学习法 | 神经网络学"位姿→关节角"映射 | 快，有误差，常配合数值法精修 |

**平面 2 连杆机械臂的核心公式**：

- 正解：`x = L1·cos(θ1) + L2·cos(θ1+θ2)`，`y = L1·sin(θ1) + L2·sin(θ1+θ2)`
- 解析逆解：`cos(θ2) = (x² + y² − L1² − L2²) / (2·L1·L2)`，`θ1 = atan2(y,x) − atan2(L2·sinθ2, L1+L2·cosθ2)`
- 数值逆解迭代：`Δθ = Jᵀ(JJᵀ + λ²I)⁻¹ · e`，其中 J 是雅可比矩阵，e 是当前位置与目标的误差。

### 1.4 6 自由度机械臂

真实工业机器人（6DOF）需同时匹配位置和姿态；7DOF 为冗余臂，存在"零空间"可在不动末端的情况下调整肘部。常用工具：IKPy、TRAC-IK、MoveIt。解析解存在的条件可参考 Pieper 准则。

## 二、VLA：视觉-语言-动作模型

### 2.1 核心思想

传统机器人是"写死的规则"：感知、规划、控制各一套算法，换任务就要重写。VLA 的思路是**一个统一大模型，输入相机图像 + 自然语言指令，直接输出机器人动作**。

```
相机图像 ──┐
           ├──> VLA 大模型 ──> 动作
"把红色方块 ─┘
 放到碗里"
```

代表工作：RT-2（Google DeepMind，动作离散化为 token）、OpenVLA（开源 7B）、π0/π0.5（Physical Intelligence，flow matching 生成连续动作）、国内 RDT、智元、银河通用等。

### 2.2 关键澄清：VLA 不显式计算坐标

不是"识别物体→算坐标→规划轨迹→逆解"，而是端到端：神经网络在海量示教数据中学会"看到这样的画面、听到这样的指令时该怎么动"。坐标、抓取姿态等知识**隐含在权重里**。

### 2.3 数据从哪来：遥操作示教

人戴 VR 手柄或用主从臂操作机器人完成任务，系统同步记录：相机图像、语言指令、关节角度（编码器直接读出）、末端位姿（正解算出）。**坐标和角度不需要人工标注**，传感器自动记录。公开数据集：Open X-Embodiment（百万级轨迹）。

### 2.4 动作表示

- **末端位姿空间**（常见）：`[Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper]`，再由逆解转成关节角。
- **关节空间**：`[Δθ1...Δθ6, gripper]`，跳过逆解，但模型绑定特定机器人。

数值输出两条路线：

| 路线 | 代表 | 做法 |
|---|---|---|
| 离散化 token | RT-2、OpenVLA | 每维切 256 个区间，当"词"生成，交叉熵训练 |
| 连续生成 | π0、Diffusion Policy | diffusion / flow matching 从噪声去噪成动作轨迹 |

**Action chunking**（ACT 提出）：一次输出未来 20~50 步动作序列，执行一段后重新观察再生成，更平滑抗抖。

### 2.5 架构与训练

```
图像 → 视觉编码器(ViT) ─┐
指令 → tokenizer ───────┼→ LLM 骨干 → 动作头 → 动作
关节状态(可选) ─────────┘
```

- 视觉编码器和 LLM 骨干借用现成多模态大模型，语义泛化能力由此而来。
- **训练 = 行为克隆**（监督学习）：给定（图像、指令、状态），预测人录下的动作，最小化预测与示教的差异。
- **推理 = 闭环控制**：每执行几步就重新看画面，抓偏了能纠回来。

### 2.6 VLA 与逆解的关系

| | 逆解 IK | VLA |
|---|---|---|
| 问题 | 位姿 → 关节角 | 图像+语言 → 动作 |
| 求解 | 推导/迭代（函数已知） | 数据学习（函数写不出） |
| 角色 | 底层执行 | 上层决策 |

**分工**：VLA 决定"末端往哪动"，逆解负责"关节怎么转"。

## 三、AI、神经网络与大模型的关系

```
AI（人工智能）
└── 机器学习（从数据学规律，而非写死规则）
    └── 深度学习（用深层神经网络）
        └── 大模型（参数量巨大的神经网络）
```

**不是所有 AI 都用神经网络**：专家系统、搜索算法（深蓝）、决策树、SVM 等都是 AI。只是 2012 年后深度学习在图像/语音/语言上碾压其他方法，"AI"才几乎成了深度学习的代名词。

### 神经网络的本质

- 单个神经元 = **加权求和 + 激活函数**：`输出 = f(w1·x1 + w2·x2 + ... + b)`。
- 权重 w 就是要学习的参数；激活函数提供非线性。
- **学习 = 调权重**：前向传播算输出 → 损失函数量化错误 → 反向传播算每个权重的"责任" → 梯度下降微调 → 重复数百万次。
- 万能逼近定理：足够大的网络可逼近任意复杂函数。
- 网络自动分层提取特征（边缘→器官→整体），无人手工设计。

## 四、大语言模型如何工作

### 4.1 四步流程

1. **分词**：文字 → token → 数字 ID。
2. **Embedding**：每个 ID → 高维向量；意思相近的词向量相近（"国王−男人+女人≈女王"）。
3. **Transformer**：自注意力机制让模型处理每个词时"回头看"全句，解决一词多义与长距离指代；几十上百层堆叠。
4. **预测下一个词**：输出词表上每个 token 的概率，逐个"接龙"生成回答。

> **大语言模型唯一做的事：给定前面的文字，预测下一个 token。**

### 4.2 训练两阶段

- **预训练**：用几万亿 token 文本做自监督学习（遮住下文让模型猜）。要猜得准，模型被迫学会语言背后的知识——知识是"接龙能力"的副产品。
- **后训练**：指令微调（SFT）教它"用户是在提问"；RLHF 用人类打分让它偏向有用、无害、诚实。

### 4.3 常见疑问

- 幻觉的根源：模型目标是"接得像"不是"说得对"，无内置事实核查。
- 知识有截止日期，时效性问题需联网搜索（RAG）。

## 五、大模型发展的六堵墙

1. **数据墙**：公开高质量文本（几百万亿 token）快被用完；合成数据有"近亲繁殖"风险。出路：私有数据、多模态、具身数据。
2. **算力与能源墙**：单次训练上亿美元、几十万张 GPU、数据中心冲向 GW 级用电。
3. **Scaling 收益递减**：参数翻 10 倍，智能提升越来越小。转向**推理时扩展**（test-time compute，如 o 系列、DeepSeek-R1 的长思考链）。
4. **架构天花板**：幻觉、上下文有限（注意力 O(n²)）、无持续记忆、缺世界模型、自回归生成慢。
5. **硬件物理极限**：制程逼近原子尺度（量子隧穿）、摩尔定律失效、**内存墙**（显存带宽增长远慢于算力，推理瓶颈常在搬数据而非计算）。
6. **评估与对齐**：benchmark 被刷爆，能力越强越难保证"按人类意图行事"。

突围方向：推理时思考、Agent、合成数据、新架构（SSM/混合架构）、具身智能。

## 六、芯片原理：从 0 和 1 到计算机

### 6.1 自下而上六层

1. **0 和 1 = 两种电压**（高/低电平）。用二进制是因为区分两种状态工程上最可靠，抗噪声。
2. **晶体管（MOSFET）**：电压控制的开关，每秒开关几十亿次。现代 CPU 有几百亿个。制程数字（3nm）反映晶体管尺寸。
3. **逻辑门**：晶体管组合出 NOT/AND/OR/XOR。两个晶体管串联 = 与门。
4. **加法器**：半加器 = XOR（和）+ AND（进位）；64 个全加器串联 = 64 位加法器，一个时钟周期完成。ALU（算术逻辑单元）由此构成。**芯片不是"理解"数学，而是数学被翻译成了电路通断规律。**
5. **存储金字塔**：寄存器(~0.3ns) → L1/L2/L3 缓存(SRAM) → 内存 DRAM(~100ns) → SSD(~100μs)。快与大可兼得，故分层折中。
6. **指令与程序**：程序也是存在内存里的 0/1 序列（冯·诺依曼架构）。CPU 循环：取指→译码→执行→写回，由时钟驱动（3.5GHz = 每秒 35 亿拍）。现代技巧：流水线、乱序执行、分支预测。指令集：x86（Intel/AMD）vs ARM（苹果 M 系列/手机）。

### 6.2 笔记本主要模块

| 模块 | 职责 |
|---|---|
| CPU | 通用计算，少数强大核心，擅复杂逻辑与串行任务 |
| GPU | 数千小核心，并行计算：图形渲染、AI 矩阵乘法 |
| NPU | 神经网络专用，低功耗本地 AI |
| 内存 RAM | 运行时工作台，断电即清空 |
| SSD | 永久存储 |
| 总线/控制器 | 各模块间数据搬运（PCIe 等） |
| 电源管理 / 时钟 | 电压分配 / 全机节拍 |

## 七、矩阵乘法、CPU/GPU/NPU

### 7.1 加权求和 = 矩阵乘法

- 1 个神经元 = 向量点积（加权求和）。
- 1 层神经元 = 矩阵 × 向量：`y = Wx + b`。
- 一批样本 = 矩阵 × 矩阵。
- 整个前向传播 = 矩阵乘法与激活函数交替：`f(W₃·f(W₂·f(W₁·x)))`。反向传播同样是矩阵运算。
- 神经网络的计算特征：**海量、独立、整齐的乘加**。

### 7.2 CPU 为什么不多做一点

- CPU 为**延迟**优化：晶体管花在控制逻辑（乱序、分支预测）和大缓存上，让单条指令流跑得快。
- GPU 为**吞吐量**优化：砍掉控制与缓存，堆上万个小核心（RTX 4090 有 16384 个 CUDA core）。
- 操作系统/浏览器等串行分支代码只能 CPU 跑；矩阵乘法这种并行活 GPU 快两个数量级。
- 算力对比：CPU ~1-2 TFLOPS，高端 GPU ~80+ TFLOPS；带宽：CPU 内存 ~80 GB/s，GPU 显存 ~1000 GB/s。**大模型推理瓶颈常在搬权重，不在算。**

### 7.3 显卡为什么比 CPU 贵

显卡是一整块子系统：GPU 芯片（608 mm²、760 亿晶体管，面积大→良率超线性下降）+ 24GB GDDR6X 显存 + 十几相供电 + 均热板三风扇散热 + 多层 PCB。CPU 只是裸芯片。另有市场因素（游戏、挖矿、AI 抢卡）。数据中心训练卡（H100/B200）一张 3~4 万美元，HBM 显存是成本大头。

### 7.4 NPU 如何为神经网络优化

核心洞察：**搬运数据的能耗比计算本身高几十到几百倍**，所以一切设计围绕"让数据少动"。

- **脉动阵列**：乘加单元（MAC）排成网格，权重驻留不动，数据流过即完成矩阵乘。
- **低精度**：INT8/INT4 量化，乘法器面积功耗降为几十分之一，模型性能几乎无损。
- **砍掉控制逻辑**：无乱序执行、无分支预测，面积全换 MAC。
- 指标为 TOPS：苹果 M4 NPU 38 TOPS，微软 Copilot+ PC 门槛 40 TOPS。优势是**省电**。
- GPU 的 Tensor Core 本质也是内嵌的脉动阵列——GPU 与 NPU 界限在模糊。

## 八、存储介质与数据寿命

### 8.1 断电保存原理

- **SSD（NAND 闪存）**：浮栅晶体管——电子被关进绝缘层包围的"笼子"，有电子=0，无电子=1。断电不丢是因为绝缘层困住电子。
  - 软肋 1：**写入磨损**，高压擦写损伤绝缘层。TLC 约 1000~3000 次 P/E，QLC 几百次；家用写寿命够用十几年。
  - 软肋 2：**电子缓慢泄漏**，温度越高漏越快。JEDEC 标准：消费级 SSD 寿命末期 30°C 断电保持 1 年。
- **HDD（机械硬盘）**：磁畴磁化方向存 0/1，不靠电维持。数据保持远好于 SSD（理论几十年），但电机/轴承/润滑脂会机械老化。

### 8.2 "50 年之问"的答案

| 介质 | 断电 50 年后 |
|---|---|
| SSD | 数据几乎肯定全丢（电子漏光） |
| HDD | 磁记录可能大部分还在，但盘体可能转不起来 |
| 普通光盘 | 染料老化，大概率读不出 |
| M-DISC 归档光盘 | 宣称百年级 |
| 磁带（LTO） | 标称 30 年，企业冷备份主流 |

家用寿命预期：SSD 5~10 年（多死于主控而非写死），HDD 年均故障率 1~2%。

> **核心结论：数据不靠"活得久的介质"保存，而靠"不断复制"保存。** 实践 3-2-1 备份：3 份副本、2 种介质、1 份异地。数字保存 = 定期迁移到新介质。

## 九、大模型如何生成回答

以"用户提问 → 看到回答"为例：

1. **分词**：整段输入（含对话历史）切成 token → 数字 ID。
2. **前向传播**：几千亿权重从 HBM 显存搬出（内存墙在此体现），Transformer 每层做矩阵乘法，注意力机制关联上下文。
3. **逐 token 生成**：输出层给词表概率分布，采样一个接上去，再算下一轮——每个字都是几千亿次矩阵乘法的结果。
4. **"思考"与结构的来源**：优秀讲解方式本身是可学习的统计模式；RLHF 强化了清晰、诚实的倾向；已生成的文字成为后续生成的上下文（边想边说）。
5. **诚实的局限**：模型无法内省自己的权重，对其"思考过程"的自我叙述也是生成的——可解释性仍是开放难题。

何时联网搜索：概念性知识直接用权重；时效性问题、拿不准的事实才搜索，否则可能幻觉。

## 十、大模型的存储占用

### 10.1 计算公式

```
存储占用 = 参数数量 × 每参数字节数
```

| 模型 | 参数量 | FP16(2字节) | INT8(1字节) | INT4(0.5字节) |
|---|---|---|---|---|
| GPT-3 | 175B | 350 GB | 175 GB | ~88 GB |
| LLaMA 3.1 | 405B | 810 GB | 405 GB | ~200 GB |
| DeepSeek V3 | 671B(MoE) | 1.3 TB | 671 GB | ~335 GB |

训练时还要存梯度和优化器状态（Adam 每参数 +2 个历史值），总需求为推理的 4~8 倍。

### 10.2 模型是互联网的"压缩包"

15 万亿 token（约 60 TB 文本）→ 350 GB 权重，压缩率约 170:1。存的是规律不是原文——所以会有幻觉。

### 10.3 知识增长 ≠ 存储无限膨胀

四条"省存储"路线：

1. **量化**：INT4 存储缩 4 倍，性能损失 <1%。
2. **蒸馏**：大模型教小模型；现在 7B 模型可追平当年 175B 的 GPT-3。
3. **MoE**：总参数大但每次只激活一小部分（如 671B 激活 37B）。
4. **RAG**：不背知识，需要时现查——模型保持"会思考"，事实靠检索。

实用判断：看新模型关注**激活参数 × 精度位数**，而非总参数量。
