## 一、机器人逆解（IK）

### 1.1 正解与逆解

- **正解（Forward Kinematics）**：已知每个关节角度 → 算出末端夹爪的空间位置和姿态。纯几何计算，答案唯一。
- **逆解（Inverse Kinematics）**：已知目标位姿 → 反推每个关节应转到多少度。

平面 2 连杆机械臂的正解公式：

```
x = L1·cos(θ1) + L2·cos(θ1 + θ2)
y = L1·sin(θ1) + L2·sin(θ1 + θ2)
```

### 1.2 逆解为什么难

1. **解不唯一**：同一目标位置可有"肘部朝上/朝下"等多个解。
2. **可能无解**：目标超出工作空间。
3. **可能没有解析解**：多数机械臂结构推不出公式，只能迭代逼近。
4. **奇异性**：某些姿态下失去运动自由度。

### 1.3 两大求解方法

| 方法 | 思路 | 特点 |
|---|---|---|
| 解析法（封闭解） | 推导数学公式直接算 | 快、精确，但只对特定构型可行 |
| 数值法 | 雅可比矩阵迭代逼近 | 通用，但慢、依赖初值 |
| 学习法 | 神经网络学"位姿→关节角"映射 | 快，有误差，常配合数值法精修 |

**解析法核心公式**（2 连杆臂，余弦定理推导）：

```
cos(θ2) = (x² + y² − L1² − L2²) / (2·L1·L2)   ← |cos| > 1 则无解
θ1 = atan2(y, x) − atan2(L2·sinθ2, L1 + L2·cosθ2)
```

**数值法核心迭代**（雅可比阻尼最小二乘 DLS）：

```
循环：
  1. 用正解算当前位置，得误差 e = 目标 − 当前
  2. 计算雅可比矩阵 J（位置对关节角的偏导数）
  3. 修正量 Δθ = Jᵀ(JJᵀ + λ²I)⁻¹ · e
  4. 更新关节角，直到误差足够小
```

### 1.4 工程实践

- 真实 6 轴机械臂多数无解析解（Pieper 准则），常用库：**IKPy、TRAC-IK、MoveIt**。
- 2DOF 平面臂只能匹配位置 (x, y)；3DOF 平面臂可匹配位置+朝向；6DOF 空间臂匹配位置+姿态；7DOF 冗余臂有零空间可避障。

## 二、VLA：视觉-语言-动作模型

### 2.1 核心思想

传统机器人 = 程序员写死规则（感知→规划→控制分层管线），换任务要重写。
VLA = **用一个统一大模型，直接输入相机图像 + 自然语言指令，输出机器人动作**。

```
相机图像 ──┐
           ├──> VLA 大模型 ──> 动作
"把红色方块 ─┘
 放到碗里"
```

**关键认知**：VLA 不是"识别物体 → 算坐标 → 规划 → 逆解"的传统管线，而是端到端学习——中间没有显式的"物体坐标"环节，空间知识隐含在网络权重里。

### 2.2 代表性工作

| 模型 | 机构 | 特点 |
|---|---|---|
| RT-2 | Google DeepMind, 2023 | 动作离散化为 token，像生成文字一样生成动作 |
| OpenVLA | 2024，开源 | 70 亿参数，基于开源多模态大模型微调 |
| π0 / π0.5 | Physical Intelligence | flow matching 生成连续动作，可叠衣服等灵巧任务 |
| RDT 等 | 国内 | 清华等机构的双臂扩散策略 |

### 2.3 数据从哪来：遥操作示教

人戴 VR 手柄或用主从臂操作机器人做任务，系统同步记录每一帧（约 30Hz）：

- 相机图像（多视角）
- 语言指令
- 关节角度（编码器直接读出）
- 末端位姿（关节角经正运动学算出）
- 动作标签 = 人下一步的操作量

**坐标和角度不需要人工标注**，机器人传感器直接给出。成本在人力操作本身。
公开数据集：**Open X-Embodiment**（百万级轨迹，几十种机器人）。

### 2.4 动作表示

两种输出空间：

1. **末端位姿空间**（更常见）：`[Δx, Δy, Δz, Δroll, Δpitch, Δyaw, gripper]` → **再由逆解转成关节角**
2. **关节空间**：`[Δθ1, ..., Δθ6, gripper]` → 跳过逆解，但绑死特定机器人

两条数值生成路线：

| 路线 | 代表 | 做法 |
|---|---|---|
| 离散化成 token | RT-2、OpenVLA | 每维切 256 个区间，交叉熵训练 |
| 连续生成（diffusion / flow matching） | π0、Diffusion Policy | 从噪声去噪成平滑动作轨迹 |

**Action chunking**（ACT 提出）：一次输出未来 20~50 步动作序列，执行一段后重新观察，动作更平滑抗抖动。

### 2.5 模型架构

```
相机图像 ──→ 视觉编码器(ViT) ──→ 图像 token ─┐
                                              ├─→ LLM 骨干 ──→ 动作头 ──→ 动作
语言指令 ──→ 文本 tokenizer ─────────────────┘    (离散token头 或 diffusion头)
关节状态(可选) ──────────────────────────────┘
```

视觉编码器和 LLM 骨干**不从头训练**，直接拿现成多模态大模型（Prismatic、Qwen-VL 等）——语义泛化能力的来源；机器人数据只微调出"输出动作"的能力。

### 2.6 训练与推理

**训练 = 行为克隆（Behavior Cloning）**，本质是监督学习：

```python
for image, instruction, state, human_action in dataset:
    pred = VLA(image, instruction, state)
    loss = 匹配损失(pred, human_action)   # 交叉熵 或 扩散损失
    loss.backward()
```

**推理 = 闭环运行**：

```python
while 任务未完成:
    image = 相机.read()
    chunk = VLA(image, 指令, 当前关节角)
    for action in chunk[:K]:
        if 动作是末端位姿: 关节角 = 逆解(action)   # ← IK 在此接棒
        电机执行(关节角)
    # 重新观察画面，闭环纠错
```

### 2.7 优势与局限

- ✅ 语义泛化强（"把喝的东西拿给我"能识别可乐）
- ✅ 一个模型干多种任务
- ❌ 极其吃数据（示教昂贵）
- ❌ 推理慢（几十~上百 ms/次）
- ❌ 精度有限（抓放可以，穿针引线难）

### 2.8 IK 与 VLA 的分工

| | 逆解 IK | VLA |
|---|---|---|
| 问题 | 位姿 → 关节角 | 图像+语言 → 动作 |
| 函数 | 已知（几何公式） | 写不出来，从数据学习 |
| 求解 | 推导 / 数值迭代 | 模仿学习 |
| 角色 | 底层执行环节 | 上层决策环节 |

**不是替代关系，而是分工**：VLA 决定"末端该往哪动"，IK 负责"关节怎么转才能实现"。

## 三、AI 基本概念与神经网络原理

### 3.1 概念包含关系

```
AI（人工智能）
 └─ 机器学习（从数据学规律，不写死规则）
     └─ 深度学习（用深层神经网络做机器学习）
         └─ 大模型（参数量巨大的神经网络）
```

**不是所有 AI 都用神经网络**：专家系统（人工规则）、搜索算法（深蓝下棋）、传统机器学习（决策树、SVM、贝叶斯）都不是。只是 2012 年后深度学习效果碾压其他方法，"AI" 才几乎成了深度学习的代名词。

### 3.2 神经网络的本质

**一个神经元 = 加权求和 + 非线性开关**：

```
输出 = f(w1·x1 + w2·x2 + w3·x3 + b)
```

- `w`（权重）：要学习的参数
- `f`（激活函数）：引入非线性，使网络能表达复杂边界
- 单个神经元能力有限，**几百万个分层堆叠**可逼近任意复杂函数（万能逼近定理）

**学习 = 调权重**：

1. 随机初始化权重（输出是瞎猜）
2. 喂数据 → 算损失（错得多离谱）
3. **反向传播**：算每个权重对错误的"贡献"
4. **梯度下降**：每个权重往减少错误方向调一小步
5. 重复几百万次

网络自动学会分层特征：低层认边缘 → 中层认部件 → 高层认整体。**没人教它这个层级，它自己长出来的。**

### 3.3 大语言模型如何工作

**第 1 步：文字 → 数字**
分词（tokenizer）→ token ID → Embedding 高维向量。
Embedding 精妙处：意思相近的词向量相近，"国王 − 男人 + 女人 ≈ 女王"。

**第 2 步：Transformer 架构（2017）**
核心 = **自注意力（Self-Attention）**：处理每个词时"回头看"句中所有词，计算相关度。解决一词多义、长距离指代。

**第 3 步：本质工作 = 预测下一个 token**

```
输入："中国的首都是" → "北京":92%  "南京":3% ... → 接龙式逐字生成
```

**回答就是逐 token 接龙接出来的**，每个 token 背后是整个网络的一次前向传播。

**第 4 步：训练两阶段**

- **预训练**：几万亿 token 文本做自监督（遮住下文让模型猜）。要猜得准，模型被迫学会语言背后的知识——知识是"接龙能力"的副产品。
- **后训练**：指令微调（SFT，学会"该回答而不是续写"）+ RLHF（人类打分，偏向有用/无害/诚实）。

### 3.4 常见疑问

| 疑问 | 直答 |
|---|---|
| AI = 大模型？ | 不是，大模型是 AI 子集 |
| 所有 AI 都用神经网络？ | 不是，但当前主流是 |
| 模型"理解"我吗？ | 哲学问题；工程上它学到的是统计上最合理的回应函数 |
| 为什么会幻觉？ | 目标是"接得像"不是"说得对"，无内置事实核查 |

## 四、大模型的发展瓶颈

### 4.1 数据墙

人类公开高质量文本约几百万亿 token，前沿模型基本用完。合成数据是出路但有"近亲繁殖"风险。物理世界数据（视频、机器人示教）几乎未开采——VLA 火热的原因之一。

### 4.2 算力与能源墙

- 单次前沿训练成本上亿美元，用几万~几十万张 GPU
- 数据中心电力冲向 GW 级（≈中型城市用电量）
- 顶级训练卡（H100/B200）单张 3~4 万美元

### 4.3 Scaling Law 边际收益递减

参数翻 10 倍，智能提升变小，成本实打实翻 10 倍。
**突围方向：推理时扩展（test-time compute）**——o 系列 / DeepSeek-R1 式推理模型，生成长思考链再作答。

### 4.4 架构天花板

| 缺陷 | 表现 |
|---|---|
| 幻觉 | 只会"接得像"，无事实核查 |
| 上下文有限 | 注意力计算量随长度平方增长 |
| 没有真正的记忆 | 每轮对话从零开始，无法持续学习 |
| 缺乏世界模型 | 只读过文字，物理理解是间接的 |
| 自回归生成慢 | 逐字蹦，延迟成本高 |

### 4.5 硬件物理极限

- 制程逼近原子尺度，量子隧穿导致漏电，摩尔定律基本失效
- **内存墙**：算力增长远快于显存带宽，推理瓶颈常在"搬数据"而非"算"

### 4.6 评估与对齐

Benchmark 快被刷爆；能力越强，对齐（按人类意图行事）越难。

## 五、芯片原理：0 和 1 如何完成一切

### 5.1 0 和 1 = 两种电压

芯片里没有数字，只有电压：高电压 ≈ 1，低电压 ≈ 0（人为约定）。
用二进制是**可靠性选择**：区分两种电压等级抗噪声，区分十种则极易出错。

### 5.2 晶体管：用电控制电的开关

现代 CPU 有**几百亿个** MOSFET 晶体管。栅极加电压 → 沟道导通；撤掉 → 断开。无机械部件，每秒开关几十亿次，尺寸几十纳米。
"3nm 制程"形容晶体管尺寸（现已是营销命名）——越小 → 同面积塞越多、越省电、越快。

### 5.3 逻辑门：开关拼出"判断"

| 门 | 功能 |
|---|---|
| NOT | 取反 |
| AND | 都为 1 才输出 1（两晶体管串联） |
| OR | 有一个 1 就输出 1 |

### 5.4 加法器：逻辑门拼出"算术"

二进制加法：`0+0=0, 0+1=1, 1+1=10`。
观察："和"位 = 异或，"进位"位 = 与 → **半加器**（2 个逻辑门）。
64 个全加器串联 = 64 位加法器，CPU 一个时钟周期完成一次加法。
减乘除、比较大小都可归结为加法+逻辑门组合。**ALU（算术逻辑单元）**就是干这个的。

> 芯片不是"理解"了数学，而是有人把数学翻译成了电路的通断规律。

### 5.5 存储金字塔

| 层级 | 材料 | 速度 | 容量 | 类比 |
|---|---|---|---|---|
| 寄存器 | 触发器 | ~0.3ns | 几百字节 | 手里的笔 |
| L1/L2/L3 缓存 | SRAM（6晶体管/bit） | ~1-10ns | KB~几十MB | 桌上草稿纸 |
| 内存 RAM | DRAM（电容） | ~100ns | 16GB | 书架 |
| SSD | NAND 闪存 | ~100μs | 512GB~2TB | 仓库 |

又快又大的存储造不出来，用金字塔折中。

### 5.6 指令：程序也是 0 和 1

冯·诺依曼架构：**程序和数据一样，都是存在内存里的 0/1 序列**。
编译器把高级语言翻译成机器码；指令集分 x86（Intel/AMD）与 ARM（苹果 M 系列/手机）。

CPU 工作循环（时钟驱动，3.5GHz = 每秒 35 亿节拍）：

```
取指 → 译码（控制单元解读） → 执行（ALU 运算/读写内存） → 写回 → 下一条
```

现代优化：流水线、乱序执行、分支预测。

### 5.7 笔记本的模块

| 模块 | 组成 | 负责 |
|---|---|---|
| CPU | ALU+控制单元+寄存器+缓存，4~16 核 | 通用计算：OS、浏览器、代码 |
| GPU | 上千~上万小核心 | 并行计算：图形渲染、AI 矩阵乘 |
| NPU | 矩阵乘加专用电路 | 本地 AI：抠图、语音唤醒 |
| 内存 RAM | DRAM | 运行时工作台，断电清空 |
| SSD | NAND 闪存+主控 | 永久存储 |
| 芯片组/总线 | PCIe 等 | 模块间数据搬运 |
| 电源管理 | — | 分配电压、管充电 |
| 时钟发生器 | 石英晶振 | 全机统一节拍 |

苹果 M 系列把 CPU/GPU/NPU/内存控制器集成进一颗 SoC。

## 六、神经网络 = 矩阵乘法；CPU / GPU / NPU 分工

### 6.1 加权求和 = 矩阵乘法

一个神经元是一次向量点积；一层神经元（3 神经元、2 输入示例）：

```
┌ y1 ┐   ┌ w11 w12 ┐
│ y2 │ = │ w21 w22 │ × x + b
└ y3 ┘   └ w31 w32 ┘
```

整个前向传播：`输出 = f(W₃·f(W₂·f(W₁·x+b₁)+b₂)+b₃)` —— 全是矩阵乘法夹激活函数。
千亿参数模型一次前向 = 几千亿次**海量、独立、整齐**的乘加。

### 6.2 CPU 为什么不多做一点

设计哲学相反：**CPU 为延迟优化，GPU 为吞吐量优化**。
CPU 把晶体管花在复杂控制（乱序、分支预测）和大缓存上，ALU 只占小面积。

| | 高端 CPU | 高端 GPU (RTX 4090) |
|---|---|---|
| 核心 | 8~24 个强核 | 16384 个小核 |
| 算力 | ~1-2 TFLOPS | ~82 TFLOPS（FP32） |
| 内存带宽 | ~80 GB/s | ~1000 GB/s |

分支密集的串行任务（OS、游戏逻辑）只能 CPU；矩阵乘法这种"海量独立口算"GPU 完胜。
"给 CPU 加一万核"= 砍掉控制逻辑 = 变成 GPU——同一份晶体管预算的两种花法。
大模型推理瓶颈常在带宽（每生成一字要把全部权重读一遍），CPU 的 80GB/s 不可用。

### 6.3 显卡为什么比 CPU 贵

显卡是一整块子系统：GPU 芯片（608mm²、760 亿晶体管，良率超线性下降）+ 24GB GDDR6X 显存 + 十几相供电 + 均热板三风扇散热 + 多层 PCB。CPU 只是裸芯片+小盖子。
外加市场因素：游戏刚需、AI 抢卡。数据中心 H100/B200 单卡 3~4 万美元，HBM 显存是成本大头。

### 6.4 NPU 怎么优化神经网络

出发点：**搬数据的能耗比计算本身高几十~几百倍** → 让数据少动、乘法器密集排布。

1. **脉动阵列**：成千上万 MAC 单元排成网格，权重驻留不动，输入流过即完成乘加，数据复用最大化
2. **低精度**：神经网络对精度宽容，INT8/INT4 乘法器面积功耗只有 FP32 的几十分之一（量化技术）
3. **砍掉控制赘肉**：无乱序无分支预测，面积全给 MAC

指标 TOPS（每秒万亿次运算）：苹果 M4 神经网络引擎 38 TOPS、仅几瓦；微软 Copilot+ 门槛 40 TOPS。
GPU 的 Tensor Core 本质就是内嵌的小脉动阵列——GPU 与 NPU 界限在模糊。

## 七、存储原理：断电保存与数据寿命

### 7.1 SSD（NAND 闪存）：把电子关进笼子

特殊晶体管多一个**被绝缘层完全包围的浮栅**：

- 写入：高电压把电子"打"过绝缘层关进浮栅
- 有电子 = 0，没有 = 1
- 断电不丢：绝缘层包裹，电子出不来

软肋：
1. **写入磨损**：高压轰击损伤绝缘层，TLC 约 1000~3000 次擦写，QLC 几百次（家用够十几年）
2. **电子缓慢泄漏**：断电丢数据的根源，温度越高漏越快。JEDEC 标准：消费级 SSD 寿命末期 30°C 断电**保证 1 年**；新盘低温可 5~10 年

### 7.2 HDD（机械硬盘）：磁畴方向

磁化方向朝上 = 1、朝下 = 0，不靠电维持。
数据保持远好于 SSD（理论几十年），但机械部件（电机、轴承、润滑脂）会老化——**数据还在，盘可能转不起来**。

### 7.3 50 年断电之问

| 介质 | 50 年后 |
|---|---|
| SSD | 数据几乎必丢（电子漏光） |
| HDD | 磁记录可能大部分还在，但机械很可能失效，需开盘抢救 |
| 普通光盘 | 染料老化，大概率读不出 |
| M-DISC 归档光盘 | 宣称百年级，家用长期存档选项 |
| LTO 磁带 | 标称 30 年，企业冷备份主流 |

家用寿命预期：SSD 正常用 5~10 年+（多死于主控而非写死）；HDD 年故障率 1~2%，平均 5 年左右。

### 7.4 最重要的原则

> **数据不靠"活得久的介质"保存，而靠"不断复制"保存。**

**3-2-1 备份**：3 份副本、2 种介质、1 份异地。数字保存 = 每隔几年迁移到新介质，如同古籍靠一代代抄写流传。

## 八、大模型如何生成回答

### 8.1 两个猜测的澄清

- 没有任何人预先写过具体问题的答案
- 概念性问题**不联网搜索**——知识在训练时压缩进了权重；只有时效性问题（新闻、股价）或需要验证的事实才搜索

### 8.2 知识存在哪：互联网的压缩包

训练读了几万亿 token（教材、维基、博客、论文），但**不存原文**——知识压缩在几千亿个权重的组合模式中（如盐的味道不存在于单个氯化钠分子）。
这就是能回答"没人问过的问题"的原因：学的不是问答对照表，而是语言与知识的内在结构，可泛化重组。

### 8.3 从按下回车到看到回答

1. **分词**：整段文字切成 token → ID；**整个对话历史**一起作为上下文输入（所以能记住之前聊过什么）
2. **前向传播**：几千亿权重从 HBM 显存搬出（内存墙！），问题向量 × 权重矩阵流过上百层 Transformer，注意力机制自动关联对话历史中的相关内容
3. **逐 token 生成**：输出词表概率分布 → 选一个 → 接入输入 → 再算一轮。每个字 = 几千亿次矩阵乘法
4. **结构从哪来**：训练时读过无数优秀讲解（"先破误解再讲原理"是可学习的模式）+ RLHF 强化清晰友好的表达 + 已生成的文字成为后续生成的上下文（边想边说）

### 8.4 诚实的局限

模型**无法内省自己的权重**，对自己"思考过程"的描述部分是设计原理、部分是生成的自我叙述——可解释性仍是核心难题。
幻觉根源：只保证"接得像"，不保证"说得对"。

## 九、大模型的存储占用

### 9.1 计算公式

```
存储占用 = 参数数量 × 每个参数占的字节数
```

| 模型 | 参数量 | FP16（2字节） | INT8 | INT4 |
|---|---|---|---|---|
| GPT-3 | 175B | 350 GB | 175 GB | ~88 GB |
| LLaMA 3.1 | 405B | 810 GB | 405 GB | ~200 GB |
| DeepSeek V3 | 671B (MoE) | 1.3 TB | 671 GB | ~335 GB |

训练时还要存梯度和优化器状态（Adam 每参数 2 个历史量），总需求为推理的 4~8 倍。

### 9.2 模型 = 有损压缩

```
训练数据 15 万亿 token ≈ 60 TB → 权重 350 GB，压缩率约 170:1
```

不存原文只存规律——所以会记错具体数字（幻觉）。

### 9.3 知识增长 ≠ 存储无限膨胀

四条"省存储"路线：

1. **量化**：INT4 存储，体积 1/4，性能损失 <1%
2. **蒸馏**：大模型教小模型，7B 可追平当年 175B，小 25 倍
3. **MoE**：总参数大（671B）但每次只激活一小部分（37B）——知识分房间存放
4. **RAG**：不背知识，需要时现查——模型保持"会思考"，事实靠检索

**趋势**：2020-2023 军备竞赛体积暴涨；2023 后两头分化——旗舰靠 MoE/量化控制开销，实用模型疯狂瘦身。
看新模型别只看参数量，看**"激活参数 × 精度位数"**——前者决定运行成本，乘积决定真实体积。
